KANTRI JUNGLE v2.0 — Game Horor 3D (HTML5)
==========================================
Intro: Maulana Studio · Latar: SMKS PGRI Singosari, Malang

CERITA
------
Seorang siswa SMKS PGRI Singosari pulang malam lewat jalan pintas hutan.
Motornya mogok. Di antara pepohonan ada sosok bergaun putih yang tertawa…
Bertahan hidup, cari bantuan, atau jelajahi hutan. Ada 15 ENDING berbeda.

CARA MAIN DI HP
---------------
1. Ekstrak ZIP ini.
2. Buka "index.html" dengan Chrome (Android) atau Safari (iPhone).
   - Android: buka aplikasi File / File Manager -> ketuk index.html -> pilih Chrome.
   - Cara paling gampang & stabil: upload folder ini ke itch.io (jenis HTML5)
     atau ke Netlify Drop (app.netlify.com/drop), lalu buka link-nya di HP.
3. Putar HP ke mode LANDSCAPE dan pakai headset.
4. Ketuk layar -> intro studio -> menu utama.

Game bisa dimainkan offline (Main Sendiri). Mabar butuh internet.

KONTROL
-------
HP:     Jempol kiri = jalan · Geser layar kanan = lihat sekeliling
        LARI (tahan, pakai stamina) · AKSI = ambil/pakai · senter · JONGKOK
        🎒 = barang, peta & petunjuk · 📱 = HP · ❚❚ = jeda
Laptop: WASD jalan · Mouse lihat (klik layar dulu) · Shift lari · E aksi
        F senter · C jongkok · Tab tas · Q HP · Esc jeda

BARU DI v2.0
------------
- HP bisa dipakai: telepon Ibu, Ayah, Dimas, Pak Darmo, atau Polisi 110,
  baca pesan masuk, buka foto catatan, nyalakan senter, lihat peta.
  Telepon butuh sinyal (lihat bar sinyal di HP). Sinyal terkuat di menara BTS.
  Hati-hati: game tetap berjalan saat HP dibuka, dan ada nomor tak dikenal…
- Mabar 2–3 orang + Chat Tim (pesan cepat & kirim lokasi ke peta teman).
- Gambar lebih tajam, efek grain/buram dikurangi (bisa dimatikan).
- UI baru, kompas, statistik di akhir permainan, layar KREDIT.
- Pilihan kesulitan (Mudah/Normal/Sulit), getar HP, tampilan FPS.

TIPS BERTAHAN HIDUP
-------------------
- Kuntilanak lebih cepat dari jalan kakimu, tapi lebih lambat dari larimu.
  Simpan stamina untuk lari di saat genting.
- Sorot dia dengan senter (bukan lampu HP) supaya silau dan melambat.
- Sembunyi di lemari, atau nyalakan api unggun di depan pondok.
- Baterai HP dipakai untuk lampu HP dan menelepon. Jangan sampai habis.
- Baca semua catatan — ceritanya membuka ending rahasia & ending sejati.

MABAR (P2P)
-----------
- Semua pemain harus terhubung ke internet.
- Pemain 1: MABAR -> BUAT ROOM -> bagikan KODE ROOM (5 huruf).
- Teman: MABAR -> ketik kode -> GABUNG. Maksimal 3 pemain (2–3 orang).
- Host menekan MULAI GAME.
- Kalau temanmu tertangkap, dekati dia dan TAHAN AKSI untuk menolong.
- Satu tim, satu nasib: ending yang terjadi berlaku untuk semua pemain.
- Teknis: server sinyal publik PeerJS (0.peerjs.com) hanya dipakai untuk
  "jabat tangan" awal; data game dikirim langsung antar-HP (WebRTC).
  Jika gagal tersambung, coba jaringan lain (mis. hotspot HP).

PENGATURAN
----------
Grafis Rendah/Sedang/Tinggi, sensitivitas kamera, kecerahan, volume,
dan ukuran tombol. Untuk HP spek rendah pilih "Rendah".

15 ENDING
---------
Buka GALERI ENDING di menu. Ending yang belum terbuka punya petunjuk.
Progres ending tersimpan di browser.
